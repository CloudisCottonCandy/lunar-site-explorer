An interactive Roblox experience for exploring lunar south-pole landing conditions.

Overview:

Lunar Site Explorer is an interactive 3D environment designed to help users explore the lunar south pole and understand how landing location and observation time affect solar illumination and Earth visibility.

The project combines lunar terrain visualisation with astronomical data from NASA/JPL Horizons.

Features:

- 3D Lunar Terrain: Explore a terrain model generated from actual lunar south-pole elevation data.
- Coordinate Navigation: Navigate to locations using latitude and longitude, or simply move around with your arrow keys.
- Time Selection: Select an observation date and time.
- Sun & Earth Visualisation: Display the apparent positions of the Sun and Earth relative to the local horizon.
- Astronomical Data: Retrieve azimuth and elevation values using NASA/JPL Horizons.
- Horizon Status: Identify whether the Sun and Earth are above or below the local horizon.
- Immerse: Click anywhere on the terrain and click spectate button to visually see the terrain, sun and earth with full 3d movement and immersion.

Data Sources:

- NASA Moon Trek: Lunar elevation data from the Lunar Reconnaissance Orbiter's Lunar Orbiter Laser Altimeter (LOLA).
- NASA/JPL Horizons System: Astronomical positional data for the Sun and Earth.

Technologies:

- Roblox Studio
- Luau (Roblox Lua)
- NASA/JPL Horizons API

Repository Contents:

This repository contains the Luau scripts used to implement the project's navigation, camera controls, interface, and astronomical data retrieval.
